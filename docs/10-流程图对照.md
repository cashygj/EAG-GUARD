## 这轮实际改的五处

1. **节点补齐**：加 `TOOL` / `OBJECT` 两类节点，与图一致。
2. **Action 加 `evidence_ids`**：对应图里的"tool + arguments + evidence_ids"。
3. **输出审核按域启用**：只在 travel；其余域不再误伤回答。
4. **澄清分支**：拒绝文案按"越权 / 证据不足"分流，后者引导补充检索。
5. **执行前核对**（上一轮）：从自比改成真正的两份数据比对。

## 仍然与图有差异的两处（有意为之）

- **证据未做字段级切片**：一次工具返回一条证据。图里画的是"切片"，实现上
  依赖 `field_extractor` 钩子（默认空）。要真正切片，需要按域写提取器
  （如把 YAML 工具输出拆成字段）。这条影响溯源粒度，不影响判定的正确性。
- **工具与对象的核对放在代码里**：图的"独立语义审核"框里第①②项，我们是
  先由代码判定并把结论作为事实交给裁判，裁判只判③④。这样更稳（模型不会
  在"工具是否在授权集"这种事实上绕圈），也与"独立判定"的意图一致。
