# 测量噪声：单次跑批不足以判断改动好坏

## 1 触发这次检查的现象

优化"banking 守卫负效应"时，做了严格 A/B（同一批 18 对、同一模型、同一代码路径）：

| 跑法 | 同样 18 对的 UA |
|---|---:|
| 早期全量跑（改动前代码） | **12/18 = 0.667** |
| A：回退数值等价改动 | **6/18 = 0.333** |
| B：加字段级数值等价 | **7/18 = 0.389** |

**A 与早期跑是同一份代码，却差了 6 对（33 个百分点）。**

## 2 结论

**banking 在 qwen3.5-27b 上的单次跑批方差可达 ±33 个百分点。**

这意味着：

- 之前所有"A 比 B 好 2 对"的结论都在噪声范围内；
- 之前"守卫效应 +0.073 / −0.133"这类分域结论也不可靠；
- 温度 0 **不等于**确定性——MoE 模型 + 批处理 + 独立裁判多次调用，
  单次结果会有实质抖动。

## 3 对已发布结论的影响

| 结论 | 是否仍然可信 |
|---|---|
| 总 UA 0.7154 vs 报告 0.7122 | **差距在噪声内**，应表述为"达到同一水平" |
| travel 0.757 显著高于报告 0.643 | 可信（差 0.114，远超噪声） |
| slack ASR 1.90% 与报告一致 | 可信（同为精确值） |
| banking "守卫负效应 −0.133" | **不可信**，需重复实验 |
| workspace 0.717 vs 0.771 | 接近噪声边缘 |

## 4 以后的实验规范

1. **任何 A/B 至少重复 3 次**，比较均值与区间，不看单次；
2. 结论只用**全量 + 配对差异**，且差异要大于噪声（banking 约 ±0.15）；
3. 回归集（41 对）的用途仅限"冒烟"——确认没崩，不作结论；
4. 需要小样本结论时，选**低方差域**（travel/slack 的表现更稳定）。

## 5 待办

- 若要给出可信的分域守卫效应，需要每域 ≥3 次重复（成本约 3× 全量）；
- 或者改用"同一批对、多次采样取多数票"的方式降低方差。

## 附：这次 A/B 里数值等价改动的处置

字段级数值等价（交易记录 `10.0` vs 模型传的 `10`）在语义上是正确的，
A/B 显示 +1 对（噪声内），**保留**；但正文层不做数值放宽
（试过，39 对 UA 0.718 → 0.538，且会采信注入文本里的金额）。
