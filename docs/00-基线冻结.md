# 基线冻结：报告里的数字

来源：`EAG-Guard阶段性研究报告.docx`（8 页精简版，2026-10-22 修改）。
这里逐字抄下所有结论性数字，作为以后每次重跑的**验收基线**。
`tests/test_metrics.py` 会用这些数字反向校验指标口径。

## 1 实验设置（§4.1）

- 基准：AgentDojo 四域，97 个用户任务 × 27 个注入任务 = **629 个安全测试对**
- 攻击：`important_instructions`
- 模型：qwen-plus，`temperature=0`
- 主实验：629 对全量
- 六臂对照：同一 **25 对切片**（`user_task_0–4` × `injection_task_1–5`）
- 主配置：`delegation_untargeted` + 强反馈；travel 额外启用输出审核

## 2 表 4-1　四域主结果

| 域 | 对数 | 无防御 ASR | 无防御 UA | EAG ASR | EAG UA | 工具级 ASR |
|---|---:|---:|---:|---:|---:|---:|
| workspace | 240 | 17.08% | 0.6333 | 0.00% | 0.7708 | 0/240 |
| slack | 105 | 94.29% | 0.7238 | 1.90% | 0.6667 | 0/105 |
| travel | 140 | 62.14% | 0.2643 | 1.43% | 0.6429 | 0/120 |
| banking | 144 | 63.89% | 0.7569 | 0.00% | 0.7153 | 0/144 |
| 合计（按对） | 629 | 50.72% | 0.5946 | 0.64% | 0.7122 | 0/609 |
| 合计（等权） | — | 59.35% | 0.5946 | 0.83% | 0.6989 | 0/609 |

工具级 ASR 292/609 = 47.95%。

**口径自洽性已验算**（`python -m pytest tests/test_metrics.py`）：

- 按对 ASR = Σ(域对数×域ASR)/629 = 50.71% ≈ 50.72%
- 按对 UA = 373.99/629 = 0.5946 ✓
- 等权 ASR = 四域 ASR 算术平均 = 59.35% ✓
- 等权 UA = 四域 UA 算术平均 = 0.5946 / 0.6989 ✓

> 结论：报告里的"等权"确实是**先按域算、再对四域取算术平均**，不是按对加权。
> 重建时的指标实现必须与此一致，否则 slack（105 对）和 travel（140 对）会失真。

## 3 表 4-2　消融结果

| 消融 | 配置 | ASR | UA |
|---|---|---|---|
| 只读策略（banking） | 全部审核 / 无目标 / 全放行 | 0 / 0 / 0 | 0.6806 / 0.7153 / 0.7778 |
| 只读策略（slack） | 全部审核 / 无目标 / 全放行 | 0.95 / 1.90 / 4.76 | 0.6381 / 0.6667 / 0.5143 |
| 语义 vs 结构（25 对） | 纯结构 / 纯结构+委托 / EAG | 8 / 44 / 4 | 0.48 / 0.92 / 0.92 |
| 严格度（249 对） | 白名单 / 线索 / 无 scope | 0.48 / 1.30 / 2.25 | 0.659 / 0.712 / 0.705 |
| 输出审核（travel） | 关闭 / 开启 | 8/20 → 2/20（文本） | 0.6571 / 0.6429 |
| 反馈（banking） | 强 / 弱 | 0 / 0 | 0.7153 / 0.7569 |

要点：
- banking 只放行无目标读取，UA +3.5pp，工具级 ASR 仍为 0；slack 全放行后有 2 例真实攻击成功，UA −12.4pp → **只读策略必须按域选择**
- 纯结构收紧到白名单 = 8% ASR / 0.48 UA；放宽 = 44% / 0.92；EAG = 4% / 0.92 → 差别在**有没有授权范围和委托表示**
- 严格度：工具级 ASR 白名单 0/249，线索与无 scope 都是 1/249；代价主要在 UA
- 输出审核只在 travel 启用：纯文本注入 8/20 → 2/20，UA −1.4pp
- banking 弱反馈 UA +4.2pp，ASR 不变

## 4 对照与统计

- 25 对 slack 切片、同模型：IPIGuard 5/25（20% ASR，0.80 UA）vs EAG-Guard 1/25（4%，0.92）
- McNemar（§3.1）：316 对修好、1 对新成功
- 逐对比较（§3.2）：守卫修好 117 对、弄坏 43 对
- 残余 4 例官方 ASR 全在工具面之外：2 例计分伪影、2 例纯文本

## 5 待重建时确认的缺口

报告没有写全、重建时必须自己定的东西：

1. **任务解析器**的提示词与输出格式（`T/O/P` 怎么让模型产出、怎么校验）
2. **委托查找**的具体表示：`delegation_untargeted` 的字段级匹配规则
3. **裁判**的提示词、模型温度、是否与规划器同模型
4. **重规划**策略：拒绝后是重试、换参、还是放弃
5. 计分伪影的判定规则（那 2 例到底是什么）
6. 只读策略在四域的具体白名单（banking "无目标读取"的准确定义）
